# pairwise-reverb-zone

进隧道、出山洞、下水时回声突然切换、尾音断、室内外混响叠加：混响区用包围盒硬切；过渡只淡入不淡出；早期反射和尾响分开算；室外风声也进室内脉冲响应；portal 连通没做低通；声源和听者不同区时取听者区；混响总线在暂停时继续；多区重叠按列表顺序；IR 采样率和混音台不一致；动态开门没更新 portal。audio/reverb_zone.py 是核心，tests/test_reverb_zone.py 15个红。要修的是：体积权重过渡；淡入淡出；早反尾响统一；室内外分流；portal 低通；声源听者双端；暂停冻结；重叠归一；IR 重采样；门状态更新。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：音视频处理；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
